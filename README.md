## 🚀 Featured — CmartBridge Rwanda

**Korea → Kigali, door to door.** An AI-powered sourcing, logistics and commerce platform connecting Rwanda to Korean stores: K-beauty, K-pop merch, phone & fashion accessories — one all-in delivered price, paid with MTN MoMo or Airtel Money.

📂 Lives in this repo: [`cmartbridge/`](cmartbridge/) — a React + Vite one-page site (EN/Kinyarwanda) with a live landed-cost estimator, plus the full Phase 1 launch kit: [90-day launch plan](cmartbridge/docs/90-day-launch-plan.md) · [pricing template](cmartbridge/docs/landed-cost-pricing-template.md) · [WhatsApp templates](cmartbridge/docs/whatsapp-message-templates.md) · [T&Cs (EN+RW)](cmartbridge/docs/terms-and-conditions.md) · [starter catalog](cmartbridge/docs/starter-catalog.md)
